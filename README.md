# Velto

Velto 是一个面向 Apple Silicon Mac 的桌面操作增强工具。它把鼠标手势、鼠标手感、窗口管理、窗口切换、输入法自动切换、按键映射、Finder 增强、截图标注、网速监控和专注模式自动开关集中到一个常驻菜单栏 App 里，目标是减少高频操作里的重复按键、窗口切换和路径处理成本。

项目使用 Swift Package Manager 构建，最低支持 macOS 26。App 以辅助应用运行，不显示 Dock 图标，通过菜单栏图标进入截图、偏好设置和重启监听。

## 功能一览

设置窗口左侧是 10 个功能模块加通用设置。每个模块页顶部有自己的总开关，模块相关的设置和调试日志开关都放在本模块页里。

| 模块 | 一句话 |
| --- | --- |
| 鼠标手势 | 按住右键画出轨迹，触发对应的快捷键 |
| 鼠标控制 | 指针速度、平滑滚动、轴向反转、滚动功能键、按钮绑定和按应用覆盖 |
| 窗口管理 | 按住修饰键 + 移动鼠标即可移动或缩放窗口，快捷键或鼠标按钮最大化 |
| 窗口切换 | 替代 `⌘+Tab` 的窗口级切换器，带实时缩略图 |
| 输入法切换 | 按 App、浏览器网站、地址栏焦点自动切输入法，可强制英文标点 |
| 按键映射 | 手动添加简单映射，或导入 Karabiner 社区规则 |
| 增强Finder | Finder 工具栏 / 右键菜单 / 全局快捷键打开终端、编辑器或拷贝路径 |
| 截图 | 全局快捷键截图，区域 / 窗口选择、标注、滚动长截图 |
| 网络监控 | 菜单栏实时网速，点开查看哪些进程在占用网络 |
| 专注自动化 | 指定 App（如视频播放器）在用时自动开勿扰，用完自动关 |
| 通用设置 | 开机启动、菜单栏图标、权限、配置备份、日志 |

设置窗口最小 960×640，会记住上次停留的页面。

## 鼠标手势

Event Tap 常驻监听右键事件：普通右键单击透传给系统菜单，右键拖动画出轨迹后才进入手势识别，匹配成功后向目标窗口发送快捷键。识别基于方向序列和弧向签名。

页面分「手势 | 设置」两个分段。

手势分段：

- 左侧是手势列表，行尾显示绑定的快捷键，末行「新建手势」。
- 右侧是选中手势的详情：重命名 / 删除、录制画布、快捷键。
- 每个手势可以录入多个轨迹样本（建议 2–3 个），支持撤销最后一个样本和清空。
- 手势也可以用鼠标按钮触发：在「鼠标按钮」里录中键、侧键等（可带修饰键），按下即发送快捷键，和轨迹任设其一或都设。目标窗口同样按「手势作用目标」，App 专属手势可覆盖同按钮的全局手势；鼠标控制里显式绑定了同一按钮时以鼠标控制为准。
- 快捷键可以填 Velto 自己的全局快捷键（如窗口管理的最大化窗口）。只想用某个按钮最大化窗口的话，直接在窗口管理里设「最大化鼠标按钮」更省事。
- 保存前会检测形状过于相近的手势，避免互相冲突。
- 作用范围：左栏顶部是「全局」和各个 App，「添加应用」可从正在运行的 App 里直接选，或从「应用程序」中选择。选中某个 App 后编辑的是它的专属手势（如给 Movist Pro 配快进 / 快退 / 播放暂停），只在手势落在这个 App 上时生效（按「手势作用目标」判定）。
- App 专属手势可以和全局手势同时生效（默认），也可以只用专属手势；同形状时以专属手势为准，列表里会标出「覆盖「后退」」/「被「快退」覆盖」。全局手势每行都能一键把形状复制成专属手势，只需改快捷键。
- 改动先进草稿，底部保存栏只在有改动、冲突或保存失败时出现。

设置分段：

- 行为：绘制时显示轨迹、乱划取消手势（中途来回乱划可直接取消）。
- 识别：手势超时时长（0.5–10 秒）、手势作用目标（鼠标指针下方窗口 / 当前活动窗口）。
- 调试：调试日志，记录轨迹和匹配诊断。

默认手势：

| 手势 | 默认快捷键 | 用途 |
| --- | --- | --- |
| 向左 | `⌘[` | 后退 |
| 向右 | `⌘]` | 前进 |
| 向上 | `⌘T` | 新建标签页 |
| 向下 | `⌘W` | 关闭标签页 |

## 鼠标控制

主要处理物理鼠标的指针、滚轮和按钮，不接管触控板的系统手势。改动即时保存。

指针：

- 移动速度 0.0–10.0，精度 0.1，可突破系统设置里 3.0 的上限。
- 直接修改系统鼠标跟踪速度，即时生效，重启后仍保持；只影响鼠标，不影响触控板。
- 不受鼠标控制总开关影响，也不进配置导出。

滚动：

- 平滑滚动、反向滚动各自可选：关 / 仅垂直 / 仅水平 / 双向。
- 可调最短步长、速度增益、尾迹长度。
- 模拟触控板模式：给合成滚动补连续滚动标记，让部分 App 更像收到触控板滚动。

滚动功能键：

| 功能 | 默认键 | 作用 |
| --- | --- | --- |
| 加速 | `⌥` | 按住时提高滚动速度 |
| 方向转换 | `⇧` | 按住时把垂直滚动转成水平滚动 |
| 禁用平滑 | `⌘` | 按住时临时透传普通滚轮事件 |

按钮绑定：录制键盘或鼠标触发键，绑定到系统动作（调度中心、应用窗口、显示桌面、截图）、快捷键、打开 App、打开文件或运行脚本。

按应用覆盖：为指定 App 单独配置滚动、滚动功能键和按钮绑定，每项都可选「继承全局设置」。

iPhone 镜像场景下对滚轮方向做了单独处理，避免和 iOS 自带惯性滚动打架。

## 窗口管理

按住修饰键 + 移动鼠标即可操作光标下的窗口：

- 移动窗口：拖动光标下窗口。
- 缩放窗口：从离光标最近的边角缩放。
- 滚轮缩放修饰键：按住后滚动滚轮，对网页、图片等内容缩放。
- 最大化快捷键：最大化光标下窗口。
- 最大化鼠标按钮：按下中键 / 侧键等（可带修饰键）最大化光标下窗口。同一按钮若被鼠标控制绑定或手势使用，以它们为准；App 专属手势只在那个 App 里优先。
- 最大化鼠标按钮 · 例外 App：App 自己要用这个按钮时（如 Movist Pro 把中键配成全屏播放）加进例外，光标在它上面时按钮原样交给 App。

目标窗口在按下修饰键那一刻锁定，并以光标处 WindowServer 栈顶窗口为准，避免拖到底下的窗口。改动即时保存。

## 窗口切换

对 `⌘+Tab` 的增强：按窗口而不只是按 App 切换，可显示实时缩略图。

- 默认触发键 `⌘+Tab`，可改成其它快捷键，但必须包含 `⌘` / `⌥` / `⌃`。
- 按住触发键循环选择，松开切换。
- 关闭模块后，`⌘+Tab` 还给 macOS 原生切换器。
- 显示于：鼠标所在屏幕、活跃屏幕或主屏幕。
- 筛选：按应用、桌面、屏幕范围过滤；分别控制最小化窗口、隐藏窗口、全屏窗口、无窗口 App 的显示策略。
- 分组：按窗口或按应用。
- 排序：最近聚焦、最近创建、字母顺序。
- 外观：缩略图、仅图标、仅标题。

实现上用 SkyLight 私有框架 + AX 枚举窗口；对 AX 零窗口暴露的 App（例如富途牛牛）退回 CGWindowList。对微信、Telegram 等 AX 行为特殊的应用做了窗口误删防护和熔断。没有屏幕录制权限时切换器仍可用，只是没有实时缩略图。

## 输入法切换

根据前台 App、浏览器当前网站、浏览器地址栏焦点自动选择输入法。总开关默认关闭，需要主动开启。页面分「通用 | 应用规则 | 浏览器规则」三个分段。

### 通用

- 全局默认输入法：无规则命中时切到它。
- 切回 App / 网站时：使用默认输入法，或恢复上次使用的输入法。
- 浏览器地址栏默认输入法：地址栏聚焦时强制切到指定输入法，常用于切英文。
- 强制英文标点：用中文输入法打字时，`, . ; ' [ ]` 等标点输出英文字符；带 `⌘` `⌃` `⌥` 的快捷键不受影响；输入法正在组字（候选框在屏）时翻页键照常透传。
- 兼容性：部分中日韩越输入法会出现「菜单栏图标变了，实际仍是英文」的半切换问题，可开启 CJKV 修复，修复方式二选一：
  - 模拟「上一个输入法」快捷键：默认推荐，不抢焦点；需要系统里启用该快捷键，缺失时页面会提示。
  - 临时输入窗口：短暂创建透明输入窗口让系统确认输入法状态，可能短暂激活 Velto。
- 调试日志。

决策优先级：

1. 浏览器地址栏默认输入法。
2. 选了「恢复上次使用的输入法」时，优先用当前上下文的会话缓存。
3. 浏览器 URL 规则。
4. App 规则。
5. 全局默认输入法。
6. 都没命中时保持当前输入法。

会话缓存只存在本次运行里，不写入配置。在某个 App 或网站里手动切了输入法会被记住；切回默认输入法则清掉对应缓存。

### 应用规则

把 App 分到中文组或英文组，每组指定一个输入法。按 `bundleIdentifier` 匹配，可从本机 `.app` 选择，显示图标和名称。

### 浏览器规则

先在「启用的浏览器」里打开对应浏览器，Velto 才会读当前标签页的 URL。

支持的浏览器：

- Safari、Safari Technology Preview。
- Google Chrome、Chromium、Arc、Dia。
- Microsoft Edge、Brave、Brave Beta、Brave Nightly。
- Vivaldi、Opera、Thorium。
- Firefox、Firefox Developer Edition、Firefox Nightly、Zen。

URL 规则支持三种匹配：

- 域名后缀：`github.com` 匹配 `github.com` 和 `docs.github.com`。
- 精确域名：只匹配完整 host。
- URL 正则：对完整 URL 做正则匹配。

URL 通过 AX 树读取 `AXURL`，地址栏焦点通过焦点元素判断；浏览器在前台时用 AX 事件加 0.8 秒兜底轮询更新。取不到 URL 时按普通 App 处理，不强行切换。

## 按键映射

- 简单映射：手动添加「从 → 到」，也可以把某个键映射为禁用。
- 导入的规则：导入 Karabiner 的 complex modifications JSON（例如 [ke-complex-modifications.pqrs.org](https://ke-complex-modifications.pqrs.org/) 上的社区规则），支持强制修饰键和 hyper 键，不支持的规则会跳过。
- Caps Lock 是切换键，Event Tap 拦不住它的物理开关，所以源键是 Caps Lock 的映射走 `hidutil` 在 HID 层改键；Velto 退出时会同步复原。
- 调试日志。

## 增强Finder

把 Finder 里的当前位置或选中项目快速交给终端、编辑器或剪贴板。由主 App、`betterfinder` 核心包和 Finder Sync 扩展组成。

集成：

- 「Finder 扩展」一行的说明文字显示扩展注册状态；「⋯」菜单里有「系统扩展设置」和「重启 Finder」。

Finder 菜单：

- 工具栏菜单默认包含：默认终端、默认编辑器、拷贝路径。
- 右键菜单可用默认菜单或自定义菜单，也可隐藏。
- 菜单图标三种样式：无、简单、原始（应用真实图标，已做缓存）。
- 拷贝路径支持转义，便于直接粘贴到 Shell。

默认应用：

- 默认终端用于工具栏第一项和「打开默认终端」快捷键；默认编辑器用于工具栏第二项和「打开默认编辑器」快捷键。
- 自动识别已安装的终端和编辑器，也可选择自定义 `.app` 或手动输入应用名（传给 `open -a`）。
- 内置支持 Terminal、iTerm、Alacritty、kitty、WezTerm、Tabby、Warp、Ghostty、GitHub Desktop、Fork、TextEdit、Xcode、Visual Studio Code、VSCodium、VS Code Insiders、Cursor、Sublime Text、BBEdit、CotEditor、MacVim、Typora、Nova、JetBrains 系列和 Android Studio。

全局快捷键：

| 动作 | 默认快捷键 |
| --- | --- |
| 打开默认终端 | 未设置 |
| 打开默认编辑器 | `⇧⌘S` |
| 拷贝路径到剪贴板 | `⇧⌘C` |

执行目标：有选中项目用选中项目；没有就用 Finder 当前目录；再取不到回退到桌面。

## 截图

全局快捷键唤起截图（默认未设置，必须包含 `⌘` / `⌥` / `⌃`），也可以从菜单栏图标进入。

- 选区：拖出区域，或自动识别触发瞬间活动 App 的窗口；取色放大镜显示像素放大、HEX 值和坐标。
- 会话内按键：
  - `空格`：复制到剪贴板。
  - `⌘S`：保存到预设目录（默认桌面，PNG），可选同时复制到剪贴板。
  - `S`：开始滚动长截图。
  - `Esc`：取消。
- 标注工具：矩形、椭圆、直线、箭头、画笔、马赛克、文字、荧光笔、序号、裁剪，支持撤销 / 重做。
- 默认标注样式可在设置页调整：颜色、线宽、字号、荧光笔不透明度、马赛克块大小、填充不透明度。
- 滚动长截图：用常驻 ScreenCaptureKit 采集流取帧，Vision 估计位移后做像素级接缝校验，拼接失败的帧会丢弃。

需要屏幕录制权限。

## 网络监控

- 菜单栏显示实时上传 / 下载速度（上行在上，下行在下）。
- 点开面板查看：
  - 按进程的流量：实时速率和累计流量。
  - 活动连接：协议、本地程序、远端地址、状态、方向。
  - 按进程或地址搜索；暂停 / 继续刷新；清空累计流量。
- 每秒刷新一次。

## 专注自动化

macOS 没有开关勿扰的公开接口，这个模块借「快捷指令」实现：先在「快捷指令」App 里建两个快捷指令，各加一个「设定专注模式」动作，分别把勿扰模式设为打开 / 关闭（默认名「勿扰开」「勿扰关」，页里可改选）。

- App 列表：默认带 Movist Pro，可从正在运行的 App 或「应用程序」里添加。每个 App 选判定方式：
  - 播放视频时：开始播放就算在用（看 App 是否持有防止显示器睡眠的断言），暂停不算结束，窗口全部关掉或 App 退出才结束。只开着空窗口不算。
  - 有窗口时：有窗口就算在用。
- 任一 App 在用 → 跑「开始时运行」的快捷指令；全部结束 → 跑「结束时运行」的。
- 窗口只算屏幕上的和最小化到程序坞的（最小化用辅助功能确认）；App 关掉后藏起来复用的窗口不算。别的桌面空间上的窗口也不算，全屏播放切走时靠播放状态维持。
- 只关自己开的：没由 Velto 打开的勿扰（手动开的）不会被关掉。关掉模块或退出 Velto 时，若勿扰是 Velto 开的会顺手关掉。
- 「开始时运行」失败（比如快捷指令还没建）时，30 秒后自动重试。
- 每 2 秒检查一次，App 退出时立即检查。页里显示当前状态，快捷指令找不到或运行失败会提示。调试日志会记下每个 App 的进程、窗口、播放状态变化，没自动开关时先看它。

## 通用设置

- 行为：开机自动启动、显示菜单栏图标。
- 权限：辅助功能、屏幕录制的授权状态，可一键跳到系统设置。
- 配置：导入 / 导出 JSON 备份。包含手势、鼠标控制、窗口管理、窗口切换、输入法切换、按键映射、截图、网络监控、专注自动化、增强Finder 和通用偏好；旧版备份缺少的字段导入时不会覆盖当前设置。
- 日志：日志文件夹，可在访达中显示。

备份不包含：macOS 各项隐私授权、Finder Sync 扩展的系统启用状态、登录项里的开机启动状态、鼠标指针速度、输入法切换的会话缓存。

## 权限

首次运行需要在系统设置里授权：

```text
系统设置 -> 隐私与安全性 -> 辅助功能
系统设置 -> 隐私与安全性 -> 输入监控
系统设置 -> 隐私与安全性 -> 屏幕与系统录音
系统设置 -> 隐私与安全性 -> 自动化
系统设置 -> 通用 -> 登录项与扩展 -> 扩展 -> Finder
```

- 辅助功能：手势、快捷键发送、窗口移动 / 缩放、窗口枚举、浏览器上下文读取都依赖它。
- 输入监控：全局按键和鼠标事件、切换器触发键、按键映射需要它。
- 屏幕录制：切换器实时缩略图、截图、滚动长截图需要它。
- 自动化：增强Finder 读取 Finder 当前目标时可能触发。
- Finder 扩展：增强Finder 的工具栏菜单和右键菜单依赖它。

## 构建和安装

常用方式是项目脚本：

```bash
./scripts/build-app.sh --run
```

脚本会：

- 构建 `Velto` 主程序和 `BetterFinderExtension` Finder Sync 扩展，生成 `build/Velto.app`。
- 构建缓存放在 `.build/`，并给构建目录打上 Dropbox（含 File Provider 版）认的忽略标记。
- 清掉 Dropbox 留下的扩展属性后，用 Apple Development 证书签名（可用 `CODE_SIGN_IDENTITY` 覆盖；退回 ad-hoc 会直接报错）。签名身份固定，重新构建不会吊销已有授权。
- 结束旧 Velto 进程，覆盖安装到 `/Applications/Velto.app`，注册并启用 Finder Sync 扩展。
- 带 `--run` 时构建完直接启动。

可选环境变量：

| 变量 | 作用 |
| --- | --- |
| `SKIP_INSTALL=1` | 只构建，不同步到 `/Applications/` |
| `SKIP_FINDER_EXTENSION_REGISTER=1` | 不注册 Finder Sync 扩展 |
| `FORCE_TCC_RESET=1` | 遇到授权问题时重置辅助功能 / 屏幕录制 / 自动化授权记录 |
| `CODE_SIGN_IDENTITY=...` | 换签名证书 |

为什么安装到 `/Applications/`：macOS 26 对 Dropbox / CloudStorage 路径下的 App 授权不稳定，ScreenCaptureKit 可能报 `-3801`；放在 `/Applications/` 路径稳定，TCC 更可靠。

运行测试：

```bash
swift test --scratch-path .build
```

核心职责：

- `AppDelegate`：主菜单、菜单栏图标、Event Tap、切换器、输入法切换、网络监控、专注自动化的启动和退出复原。
- `EventTapManager`：常驻的全局鼠标 / 键盘事件入口，分发到手势、鼠标控制、窗口管理、按键映射；各模块是否生效由各自开关在分发处判定。
- `Gestures/`：手势录制、识别、冲突检测、轨迹显示和快捷键触发。
- `MouseControl/`：指针速度、平滑滚动、滚动功能键、按钮绑定、按应用覆盖。
- `WindowManagement/`：窗口拖动、缩放、最大化、内容缩放。
- `Switcher/`：窗口枚举、缩略图、Key Tap、切换面板、筛选排序。
- `InputSourceSwitch/`：前台上下文监听、浏览器 URL 读取、规则决策、TIS 切换、CJKV 修复、强制英文标点。
- `KeyRemap/`：简单映射、Karabiner 规则导入、hidutil Caps Lock 改键。
- `Screenshot/`：截图会话、选区与窗口识别、标注画布、滚动长截图。
- `NetworkMonitor/`：菜单栏网速、进程流量与连接面板。
- `FocusAutomation/`：轮询指定 App 的窗口 / 播放状态，经快捷指令开关勿扰。
- `AxDeadPids.swift`：AX 无响应 App 的 pid 级熔断。

## 注意事项

- 仅面向 Apple Silicon 和 macOS 26。
- 鼠标手势只支持右键触发；鼠标控制面向物理鼠标。
- 输入法自动切换默认关闭。
- 窗口切换器使用 SkyLight 私有框架，不适合上架 Mac App Store。
- 默认 Bundle Identifier 是 `com.face.myapp`，偏好也存在这个域里；公开分发前建议改成自己的反向域名。
- 仓库没有声明开源许可证，正式公开前需要添加 `LICENSE`。
