## 一句话

现在的问题不是"不够花",而是**同一件事有好几种做法、玻璃叠了好几层、页面没有统一骨架**。
这次改版的主线是"收":一套页面骨架、一种行、一层玻璃、一种保存方式,顺手理顺几处别扭的交互。
每个阶段都应该净删代码。

## 2. 设计原则

1. **一个页面骨架**:页头(模块图标 + 标题 + 一句说明 + 总开关)→ 可选分段 → 若干分组 → 页尾固定「调试」。
2. **一种行**:标题 + 至多一行描述 + 右侧控件;更长的解释放悬停提示(`.help`)。
3. **一层玻璃**:同一块区域只允许一层玻璃,卡片里面的东西一律实色。
4. **能用原生就用原生**:按钮、分段、开关、弹出菜单、颜色选择都用系统控件;只有键帽/快捷键录制框和手势画布自绘。
5. **就近操作**:「+ 添加」「导入…」放在所属分组标题右侧;空状态是卡片里的一行字。
6. **收,不加**:不加新配置项、不加按应用粒度、不加两级开关;每个阶段净删代码。

## 3. 设计系统(DesignSystem.swift)

### 3.1 颜色 token

| 现有 | 现值 | 改为 |
|---|---|---|
| `mgSidebar` `mgCard` `mgGlassWeak` `mgGlassControl` `mgAccentSoft` | 全是 `controlBackgroundColor` | 只留 `mgCard` |
| `mgAccent` `mgAccentEnd` `mgAccentDeep` | 全是 `controlAccentColor` | 只留 `mgAccent` |
| `mgGreen` | 写死 RGB(0x34,0xC7,0x59) | `systemGreen`,深色模式自动适配 |
| `mgCardAlt` `mgHairStrong` | | 迁移完没有引用就删 |

### 3.2 字号(只留整数)

| 现有 | 改为 | 用途 |
|---|---|---|
| `mgPageTitle` 30 bold | 22 bold | 页头标题 |
| `mgTitleM` 21 bold | 17 semibold | 手势详情里的名称 |
| `mgLabelStrong` 14.5 semibold | 14 semibold | 强调行标题 |
| `mgBody` 14 | 不变 | 行标题、正文 |
| `mgBodyMedium` 13.5 semibold | 并入 `mgButtonSm` 13 semibold | |
| `mgSubLabel` 12 semibold + 字距 | 13 semibold、次级色、去字距 | 分组标题 |
| `mgMeta` 12 | 不变 | 描述、辅助信息 |
| `mgTag` 11.5 bold | 删 | 随英文 tag 一起删 |

页面里写死的 `size: 12.5`(`GeneralSettingsPage.swift:73`)一并取整;`MGSegmentedPicker` 里的 13.5 随组件一起删。

### 3.3 圆角

- `cardLg`/`card`/`cardSm`(16/16/14)合并为 `card` 16。
- `control`/`controlSm`(11/10)合并为 `control` 10。
- `kbd`/`kbdMd`/`kbdLg`(7/8/9)合并为 `kbd` 8。

都取现有最常用的值,视觉上几乎没变化,只是少 5 个 token。

### 3.4 材质(已定:方案 B)

两个方案共同的部分是**去掉内层玻璃**:键帽 `Kbd` 改实色;删 `KeyCapSlot` 外框和 `ActionIcon` 玻璃方块;卡片里的按钮改原生(见 4.1)。

| | 方案 A:卡片保留玻璃 | 方案 B:玻璃只留在导航层(推荐) |
|---|---|---|
| 卡片 | 维持 6 月的决定:玻璃 + 8% 淡底 | 实色分组底 `quaternarySystemFill`,不加描边 |
| 玻璃留在 | 卡片、侧栏、侧栏选中项、保存栏 | 侧栏、侧栏选中项、保存栏、弹出面板 |
| 依据 | 尊重已批准的设计 | macOS 26 的系统设置就是这么做的;Apple 对 Liquid Glass 的建议是只用在浮于内容之上的导航/控件层 |

已定 B,推翻 6 月那份设计里"卡片保留约 8% 淡底 + 玻璃"的决定。
原计划写的"浅色白底"落地时不成立:页面底 `windowBackgroundColor` 在浅色下本身就是白的,白卡片会和页面融成一片。
改用系统填充色 `quaternarySystemFill`:浅色是白页上一层浅灰卡,深色是比页面略亮的灰卡,和系统设置一致。
卡里的凹槽(录制框、缩略图)用 `secondarySystemFill`。卡片材质集中在 `View.mgCard()` 一处。

### 3.5 accent 色和图标

- accent 色只用在:侧栏选中项、主按钮、开关、链接、列表选中行。
- 行内的装饰性图标全部删除(`ActionIcon`,截图/切换器/输入法/增强 Finder/窗口管理 5 页在用)。
- 信息性图标保留:App 图标、浏览器图标,它们本身就是数据。
- 模块的颜色识别交给侧栏和页头的模块图标(见第 5 节)。

### 3.6 内容限宽

- 页面内容 `maxWidth: 720` 居中;鼠标手势页是列表 + 详情两栏,不限宽。
- 限宽后,窗口最小尺寸可以从 1100×720 降到 960×640(手势页列表列 360 → 320)。
- 要改两处:`SettingsRootView` 的 `.frame(minWidth:…)` 和 `AppDelegate.openSettings()` 里的 `minSize`。

## 5. 侧栏与窗口(SidebarView.swift / SettingsRootView.swift)

- 10 个手写的 `SidebarItem` 改成 `ForEach`;`MGPage` 加一个 `section` 属性区分「功能/偏好」。约 75 行 → 10 行。
- 记住上次停留的页面:用 `@AppStorage` 存页面 rawValue(落在 `com.face.myapp` 域),不再每次都打开鼠标手势。
- 删掉手势数量角标:它是整栏唯一的角标,信息和手势页列表重复。
- 模块图标改成系统设置式的彩色圆角方块(侧栏 20pt、页头 32pt,每个模块一个系统色)。可选,但这是让整体"像个成品"性价比最高的一笔。
- 关闭的模块在侧栏灰显:可选,倾向先不做。6 个模块的开关在 `GestureStore.preferences`,按键映射和增强 Finder 各在自己的 store,得同时观察 3 个 store。
